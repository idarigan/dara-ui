# Getting Started

## Install

```bash
npm install dara-ui
# or
pnpm add dara-ui
yarn add dara-ui
```

Peer dependencies: `react` and `react-dom` (18+).

## Import styles

```tsx
// main.tsx or App root
import "dara-ui/style.css";
```

## Minimal setup

```tsx
import { ThemeProvider, Button, ToastProvider } from "dara-ui";
import "dara-ui/style.css";

export default function App() {
  return (
    <ThemeProvider defaultTheme="nightfall">
      <ToastProvider>
        <Button variant="primary">Hello Dara</Button>
      </ToastProvider>
    </ThemeProvider>
  );
}
```

## With i18n + direction

```tsx
import {
  ThemeProvider,
  ToastProvider,
  I18nProvider,
  translations,
} from "dara-ui";

export default function App() {
  return (
    <ToastProvider>
      <I18nProvider translations={translations} defaultLanguage="en">
        <ThemeProvider defaultTheme="nightfall">{/* app */}</ThemeProvider>
      </I18nProvider>
    </ToastProvider>
  );
}
```

`I18nProvider` sets `lang` and `dir` on `<html>`. Components listen to `dir` for RTL.

## Tailwind / CSS variables

Dara UI ships design tokens as CSS custom properties (see `tokens.css`). Themes switch with:

```html
<html data-theme="nightfall"></html>
```

or via `ThemeProvider` / `ThemeChanger`.

## TypeScript

All public components export typed props. Example:

```tsx
import type { ButtonProps, BadgeProps } from "dara-ui";
```

## Storybook

This docs site is Storybook. Run locally:

```bash
npm run storybook
```
