# Dara UI

**Glass-heavy design system** — cyberpunk archive aesthetics, soft glow, and production-ready React components.

Dara UI mixes glassmorphism, cyberpunk HUD energy, and clean Apple-like spacing. Every interactive piece is theme-aware (`nightfall`, `daylight`, `dracula`), RTL-ready, and documented with live Storybook stories.

## What you get

- **30+ components** — buttons, forms, navigation, RPG widgets, product/blog cards
- **3 themes** out of the box via `data-theme`
- **RTL / i18n** — `dir` inheritance, LanguageChanger, translations
- **Motion** — scale-in modals, spring radios, range sparkles, 3D card tilt
- **Tokens** — CSS variables for color, radius, shadow, easing

## Quick peek

```tsx
import { Button, Badge, ThemeProvider } from 'dara-ui';
import 'dara-ui/style.css';

function App() {
  return (
    <ThemeProvider defaultTheme="nightfall">
      <Button variant="primary" glow>
        Launch mission
      </Button>
      <Badge variant="success" glow>
        Online
      </Badge>
    </ThemeProvider>
  );
}
```

## Design principles

1. **Glass first** — translucent surfaces, blur, soft borders
2. **Glow with purpose** — accent light on focus, active, and success states
3. **Motion is feedback** — animations answer user actions, never decorate randomly
4. **Mirror for RTL** — layout flips with `dir`, not hard-coded left/right
5. **Tokens over magic numbers** — themes swap by changing CSS variables
