## Features

- ✅ Auto-detects themes from CSS
- ✅ Icon-only mode for navbars
- ✅ Fixed width support
- ✅ Persists preference in localStorage
- ✅ Controlled and uncontrolled modes
- ✅ Open upward option

---

## Usage

```tsx
import { ThemeChanger } from "dara-ui";

// Full mode
<ThemeChanger />

// Icon only for navbar
<ThemeChanger iconOnly size="sm" />
```
