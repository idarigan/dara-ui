## Smart Deadline Formatting

The deadline prop intelligently formats dates:

```tsx
<QuestCard deadline="tomorrow" />  // "⏰ Deadline: Tomorrow"
<QuestCard deadline="tonight" />   // "⏰ Deadline: Tonight"
<QuestCard deadline="3 days" />    // "⏰ Deadline: 3 days"
<QuestCard deadline="2024-12-25" /> // "⏰ Deadline: 2 months"
```
