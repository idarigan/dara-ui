## Types

| Type       | Description                     |
| ---------- | ------------------------------- |
| `text`     | Default text input              |
| `password` | Password with toggle visibility |
| `search`   | Search input with clear button  |
| `email`    | Email address input             |
| `tel`      | Telephone number                |
| `number`   | Numeric input                   |
| `url`      | URL input                       |
| `date`     | Date picker                     |

---

## Validation States

| State     | CSS Class        | Use Case        |
| --------- | ---------------- | --------------- |
| `success` | `border-success` | Valid input     |
| `error`   | `border-danger`  | Invalid input   |
| `warning` | `border-warning` | Needs attention |

---

## Icons

Add icons with `leftIcon` and `rightIcon`:

```tsx
<Input
  leftIcon={<UserIcon />}
  rightIcon={<CheckIcon />}
  placeholder="Username"
/>
```
