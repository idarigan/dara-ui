## Status Indicators

| Status    | Color  |
| --------- | ------ |
| `online`  | Green  |
| `away`    | Yellow |
| `busy`    | Red    |
| `offline` | Gray   |

---

## Do's and Don'ts

### ✅ Do

- Use avatars for user identification
- Use fallbacks for missing images
- Use status indicators for presence

### ❌ Don't

- Don't use avatars without alt text
- Don't make avatars too small
