## Variants

| Variant      | Description            |
| ------------ | ---------------------- |
| `horizontal` | Linear progress bar    |
| `radial`     | Circular progress ring |

---

## Colors

| Color       | Use Case                           |
| ----------- | ---------------------------------- |
| `primary`   | Default progress                   |
| `secondary` | Secondary progress                 |
| `accent`    | Accent colored                     |
| `success`   | Completed progress                 |
| `danger`    | Error state                        |
| `warning`   | Warning state                      |
| `gradient`  | Gradient from primary to secondary |

---

## Label Positions (Horizontal)

| Position | Description          |
| -------- | -------------------- |
| `left`   | Label on the left    |
| `right`  | Label on the right   |
| `top`    | Label on top         |
| `bottom` | Label on bottom      |
| `inside` | Label inside the bar |
