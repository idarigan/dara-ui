## Features

- ✅ Glass styling
- ✅ Live value display with prefix/suffix
- ✅ Sparkle animation at max
- ✅ Multiple color variants
- ✅ RTL support
- ✅ Touch support

## Value Positions

| Position | Description        |
| -------- | ------------------ |
| `left`   | Value on the left  |
| `right`  | Value on the right |
| `top`    | Value on top       |
| `bottom` | Value on bottom    |
