## Placements

| Placement      | Position                |
| -------------- | ----------------------- |
| `top`          | Above the trigger       |
| `bottom`       | Below the trigger       |
| `left`         | Left of the trigger     |
| `right`        | Right of the trigger    |
| `top-left`     | Top-left of trigger     |
| `top-right`    | Top-right of trigger    |
| `bottom-left`  | Bottom-left of trigger  |
| `bottom-right` | Bottom-right of trigger |

---

## Variants

| Variant   | Style                   |
| --------- | ----------------------- |
| `glass`   | Glassmorphism           |
| `solid`   | Solid background        |
| `outline` | Transparent with border |

---

## Do's and Don'ts

### ✅ Do

- Use tooltips for supplementary information
- Keep tooltip text concise
- Use proper placement based on context

### ❌ Don't

- Don't put critical information in tooltips
- Don't make tooltips too long
